Ejemplo: tu primer LED parpadeante (Arduino)

Arduino C++ 
// El clásico "Hola Mundo" de la electrónica
const int LED_PIN = 13;   // Pin donde conectas el LED

void setup() {
  pinMode(LED_PIN, OUTPUT); // Configura el pin como salida
}

void loop() {
  digitalWrite(LED_PIN, HIGH); // Enciende
  delay(1000);                  // Espera 1 segundo
  digitalWrite(LED_PIN, LOW);  // Apaga
  delay(1000);                  // Espera 1 segundo
  // loop() se repite infinitamente → el LED parpadea
}
Tip: Empieza con Arduino Uno (~$10 USD en AliExpress). Tiene la comunidad más grande, miles de tutoriales y librerías para casi cualquier sensor.

Control PID — el algoritmo estrella

PID = Proporcional + Integral + Derivativo. Hace que un robot mantenga una trayectoria, velocidad o posición sin desviarse. Ejemplo: el control de temperatura de una impresora 3D usa PID.

Python — PID básico 
class PID:
    def __init__(self, kp, ki, kd):
        self.kp = kp  # Proporcional: reacciona al error actual
        self.ki = ki  # Integral:     acumula el error pasado
        self.kd = kd  # Derivativo:   predice el error futuro
        self.prev_error = 0
        self.integral   = 0

    def compute(self, setpoint, measurement, dt):
        error      = setpoint - measurement
        self.integral  += error * dt
        derivative  = (error - self.prev_error) / dt
        output      = (self.kp * error +
                       self.ki * self.integral +
                       self.kd * derivative)
        self.prev_error = error
        return output

# Uso: mantener un robot a 50 cm de una pared
pid = PID(kp=1.2, ki=0.01, kd=0.4)
velocidad = pid.compute(setpoint=50, measurement=sensor_cm, dt=0.05)

N4 ROS2 y simulación 2–4 meses ▶

ROS2 (Robot Operating System 2) es el estándar de la industria robótica. No es un sistema operativo — es un middleware que conecta módulos independientes: sensores, navegación, visión, manipuladores. Lo usan Boston Dynamics, NASA y casi todos los robots comerciales serios.

Prerrequisito: Domina Python y Linux antes de entrar a ROS2. Sin eso, la curva de aprendizaje se vuelve innecesariamente dura.

Conceptos fundamentales de ROS2

Tu primer nodo en Python

Python — ROS2 nodo publicador 
import rclpy
from rclpy.node import Node
from std_msgs.msg import String

class MiRobot(Node):
    def __init__(self):
        super().__init__('mi_robot')
        # Crea un canal llamado "estado" donde publicará mensajes
        self.pub = self.create_publisher(String, 'estado', 10)
        # Llama a publicar() cada 0.5 segundos
        self.create_timer(0.5, self.publicar)

    def publicar(self):
        msg = String()
        msg.data = 'Robot activo 🤖'
        self.pub.publish(msg)
        self.get_logger().info(msg.data)

def main():
    rclpy.init()
    rclpy.spin(MiRobot())  # Corre el nodo hasta Ctrl+C
    rclpy.shutdown()

Mecánica y actuadores

El cuerpo del robot. Aquí decides cómo se mueve.

Servomotor — el actuador más versátil

Arduino — control de servomotor 
#include <Servo.h>  // Librería para servos

Servo miServo;

void setup() {
  miServo.attach(9);  // Servo conectado al pin 9
}

void loop() {
  // Barrer de 0° a 180° y regresar
  for (int angulo = 0; angulo <= 180; angulo++) {
    miServo.write(angulo);
    delay(15);  // 15ms para que el servo llegue
  }
  for (int angulo = 180; angulo >= 0; angulo--) {
    miServo.write(angulo);
    delay(15);
  }
}

Control PID

El algoritmo fundamental para que un robot se mueva con precisión. Está en absolutamente todo: impresoras 3D, drones, brazos industriales, autos eléctricos.

Intuición: Imagina que intentas conducir un carro manteniendo exactamente 60 km/h. Acelerarás más si vas lento (P), recordarás cuánto tiempo llevas lento (I), y soltarás el acelerador antes de llegar a 60 para no pasarte (D). Eso es PID.

¿Cómo ajustar las ganancias?

Kp muy altoEl sistema oscila y no se estabiliza
Kp muy bajoTarda mucho en llegar al objetivo
Ki corrigeEl error estático residual de P solo
Ki muy altoOscilación por acumulación del integral
Kd amortiguaReduce sobreimpulso y oscilaciones
Kd muy altoRuido del sensor se amplifica

Visión artificial

Hacer que el robot "vea" y entienda su entorno.

Detección de objetos con OpenCV

Python — detectar objetos con YOLO + cámara
from ultralytics import YOLO
import cv2

# Cargar modelo preentrenado (descarga automática ~6MB)
model = YOLO('yolov8n.pt')  # 'n' = nano, muy rápido

# Capturar desde la cámara del robot
cap = cv2.VideoCapture(0)

while True:
    ret, frame = cap.read()
    resultados = model.predict(frame, conf=0.5)

    for obj in resultados[0].boxes:
        clase = model.names[int(obj.cls)]
        confianza = float(obj.conf)
        print(f"Veo: {clase} ({confianza:.0%})")

    cv2.imshow('Robot Vision', resultados[0].plot())
    if cv2.waitKey(1) == 27: break  # ESC para salir

Glosario

Los términos que más verás en tutoriales y papers.

DOFDegrees of Freedom — grados de libertad. Un brazo con 6 DOF puede alcanzar casi cualquier posición y orientación en el espacio.
MCUMicrocontroller Unit. Chip que corre un programa en bucle (Arduino, ESP32, STM32). Sin sistema operativo, control directo del hardware.
SBCSingle Board Computer. Computadora completa en una placa (Raspberry Pi). Corre Linux, soporta Python, ROS2, IA.
PWMPulse Width Modulation. Técnica para simular voltaje analógico con señales digitales. Controla la velocidad de motores cambiando el ancho del pulso.
I2CProtocolo de 2 cables (SDA + SCL) para conectar múltiples sensores al mismo bus. Cada sensor tiene una dirección única (ej: 0x68 para MPU-6050).
SLAMSimultaneous Localization and Mapping. El robot construye un mapa de su entorno mientras simultáneamente determina su posición dentro de ese mapa.
IMUInertial Measurement Unit. Sensor que combina acelerómetro + giroscopio (y a veces magnetómetro). Mide orientación y movimiento. Fundamental en drones.
OdometríaEstimar la posición del robot a partir del movimiento de sus ruedas (encoders). Acumula error con el tiempo — por eso se combina con LiDAR o GPS.
CinemáticaEstudio del movimiento sin considerar fuerzas. Cinemática directa: dado ángulos de articulaciones → posición del extremo. Inversa: dado posición → ángulos.
FirmwareSoftware que vive dentro del microcontrolador. Controla el hardware directamente. Se actualiza por USB o JTAG.
ESCElectronic Speed Controller. Convierte señales PWM en la corriente trifásica que necesitan los motores BLDC (drones). También actúa como BEC (regulador de voltaje).
URDFUnified Robot Description Format. Archivo XML que describe la geometría, articulaciones e inercias de un robot. ROS2 y Gazebo lo usan para simulación.
